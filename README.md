# 🌤️ Weather App

A modern and responsive weather application built using **React** and
**Express.js** that provides current weather conditions, hourly
forecasts, and upcoming weather information for a searched city.

## 🚀 Live Demo

🔗 https://weather-three-amber-55.vercel.app/

## ✨ Features

-   🌍 Search weather by city
-   🌡️ Display current temperature and weather condition
-   💨 Show wind speed and condition
-   💧 Display humidity
-   ☀️ Display UV index
-   🕐 Hourly weather forecast
-   📅 Upcoming/daily weather forecast
-   🌡️ Display feels-like temperature and high/low temperature
-   📱 Responsive and clean user interface
-   🔄 Fetches weather information from an external weather API

## 🛠️ Tech Stack

-   ⚛️ React
-   🟢 Express.js
-   🟨 JavaScript
-   🌐 HTML
-   🎨 CSS
-   ☁️ WeatherAPI

## 🔌 API Integration

The application uses **WeatherAPI** to retrieve real-time and forecast
weather data.

The user enters a city name, the application sends a request to the
backend/API, receives the weather data, and displays the relevant
information such as temperature, humidity, wind, UV index, and forecast.

## ⚙️ Installation

``` bash
git clone https://github.com/NikhilBuilds07/Weather-App.git
cd Weather-App
npm install
npm run dev
```

Create and configure the required environment variables for the weather
API before running the application.
